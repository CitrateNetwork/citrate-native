## Per-section verdicts

### Dashboard — Needs redesign
- Use the **marquee logo** (custom font) in the sidebar, not the icon mark.
- **Space Grotesk not visible in title fonts** (regression/diagnosis: old theme had SG
  as app-wide body default; new body=Geist and nothing applies font-display → headings
  lost SG).
- Chat loader **clipped by its container** — visually cuts the ring edges. Make smaller
  / give overflow room.

### Wallet — Buggy + visual + missing → UX RETHINK
> "This isn't for crypto people persay… How do we make this relative to a housewife and
> a crypto person. It isn't very user friendly. I would like to work that out."
- Requires a design workshop WP (dual-persona wallet), not just polish.

### DAG Explorer — visual + data-stale + redesign
- "Steal from citrate-explorer" design-wise.
- **All information should be tractionable through a side drawer that brings up the
  chatbot/agent** to talk through issues/findings → contextual agent-drawer pattern
  (likely app-wide, starts here).

### Chat — visual + missing
- Extend the agent harness as far as possible **without breaking the security threshold**
  of agent or node.
- Clearer formatting of incoming streams.
- User AND model should interact with image-gen / other loaded models.
- **Drag-and-drop for a long standardized list of misc file types.**

### Models — visual + buggy → PRIORITIZE S3 REBUILD
> "I'm not into hiding things, lets just prioritize this rebuild as it is crucial for
> pinning models and making them available to users… and so they can contribute models."
- S3 (PIN storage) priority raised; no hiding/stubbing.

### Compute — visual + buggy + missing
- Cards don't properly fit the machine information.
- **Advanced settings for super users** (granular config).
- **Seed/propagate models for initial distribution — Gemma models pinned first** once
  PIN is ready (ties to S3 + distribution plan).

### Storage — rebuild (keep tab visible)
- Keep ease of use; user must **feel guaranteed data is properly encrypted at rest**
  (see encryption:false finding above — currently NOT true; must be fixed, not just
  messaged).

### Learn — Rethink with SPINE-S1 ("generally blahhh")
- Rethink the module altogether: paths integrating learning-center/education so it's
  cohesive with **parents' and teachers' personal accounts and missions**, plus a path
  to explore open federated-learning runs.
- **Federated gateway droplet cited in docs/site is probably NOT up** — verify/stand up.
- **There should ALWAYS be a joinable pool** — seed a general pool, keep it available
  to join/contribute even when inactive.
- Study the `nat` repo + the coop work to make this cohesive.

### Agent Center — missing/unintuitive
> "I don't even understand how to use it." → dummy-proof redesign; unclear if functional.

### Settings + shell — visual + buggy + missing
- Add **Identity settings** + **connections with the other federation apps**.
- Layout: Node Control + System Health side-by-side (2-col row); Environment + Peer
  Connections likewise; stop full-width cards with empty space ("seems baked into the
  theme, not on purpose").
- Settings should get **its own sidebar** and follow the other applications' settings
  formulas.
- **Deeper Knowledge Graph settings** + investigate **citrate-memories integration for
  every node operator**: global knowledge + private knowledge, granular sharing,
  private-by-default.
